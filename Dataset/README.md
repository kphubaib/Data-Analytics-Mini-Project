## Dataset Description

The dataset contains chocolate sales transactions across multiple countries, products, sales channels, and salespersons. It was used for data cleaning, transformation, data modeling, and interactive dashboard development in Power BI.

The original dataset is publicly available through Kaggle and is used in accordance with Kaggle's dataset-sharing policies.

## Data Preparation Summary

The dataset was cleaned and prepared before being imported into Power BI. The data preparation process included:

- Correcting data types (Text, Date, and Numeric).
- Standardizing the Amount column.
- Handling missing Order Date records.
- Replacing missing numeric values using the Median method.
- Cleaning inconsistent text values.
- Validating data quality using Power Query.
- Creating calculated columns and measures for dashboard analysis.

The cleaned dataset was then used for data modeling, DAX calculations, and dashboard development.
